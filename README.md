# 超肥牛牛 ── 操作台

線下桌遊「超肥牛牛」的投影輔助程式。**玩家用實體紙牌**，這台筆電接投影機顯示全場狀況、計算牛的行動、把結果演出來。一個人當操作員。

- 單機、**無連線、無 server(選用)、無資料庫、無帳號**。
- 狀態存記憶體，每次動作自動存一份到 `localStorage`，筆電當掉可還原。
- 為投影設計：深色底、高對比、大字。

依最初的建置需求與規則書 v6 實作，並經模擬測試修正為 **規則 v19**。

- **玩家看的規則：`說明書.md`**（v19，現行預設）
- **模擬測試數據：`平衡測試報告.md`**（約 5 萬場電腦對局、規則演變）
- **待辦與改進想法：`設計改進方案.md`**（還沒實作）

## 執行

**方法一：直接開檔（最簡單）**
用瀏覽器打開 `index.html` 即可。不需安裝任何東西。

**方法二：npm start（附小型靜態伺服器）**
```bash
npm start           # → http://localhost:5173
```
零依賴，`server.js` 只是個 40 行的靜態檔案伺服器。

> 投影視窗用 `window.open` 開第二個視窗（純顯示、無控制項）。用 `file://` 直接開檔時投影視窗一樣可用（透過 `postMessage` 同步）。

## 測試（牛的演算法）

牛的演算法是唯一不能錯的部分，附完整單元測試：
```bash
npm test            # node 執行，37 項全綠
```
或用瀏覽器開 `tests.html` 看結果。

必寫的八個情況全部涵蓋並通過：**繞路、撞牆、半路停下、目標封死、平手取最近、平手取順時針、波及範圍、起點不殺人**（另加連通性、環境卡封死擋除、毒暴斃、結算順序、攜帶噪點）。

## 操作流程

每回合三步，跟著螢幕底部的控制列走：

1. **翻牌登錄** — 全場翻牌後，開登錄面板，把每人出的牌點進去（只顯示手上還有的牌，殘響一張）。中途可以按「👁 先看地圖」或 Esc 關掉，同一回合內已點的牌會保留。
2. **依序宣告** — 程式算出隊列（離牛最近先），逐一輪到每位玩家。點一張牌 → 點地圖設定目標 → 立即結算、地圖當場更新、**紅色預告線即時重畫**。
3. **結算** — 按「結算並演出牛的行動」，牛逐格移動（每格約 0.6 秒），被輾到的格子標紅，演完顯示摘要。

### 地圖上怎麼設定目標
- **移動**：點綠色格（最多 2 格、被牆擋的會反灰）
- **誘導**：點綠色範圍內一格；**屠夫**身上有樣本時可勾「☣ 投入 1 樣本下毒」
- **環境**：點自己房間的相鄰房間，切換那面牆（造成封死/切斷會被擋並提示）
- **結算後噪點**：格子裡黃色小標籤「→ 12」是回合結算後的噪點（牛實際看到的數字），跟大數字不同時才出現。
- **互動**：點「確認互動」（回聲器要再點一個相鄰房間；消音器會用綠框標出會被清掉的 5 格）。殘響的互動只能操作回聲器。
- **重製**：點「確認重製」
- **交付／丟在地上**（不是牌）：同房有活著的隊友時出現綠色「🤝 交付給某某」，身上有樣本時出現「⬇ 丟在地上」，點了再選數量。出完牌才走進隊友房間時，控制列會停住，讓你選「交付」或「下一位」。

## 快捷鍵
| 鍵 | 功能 |
|---|---|
| `Enter` | 進下一步（翻牌 / 結算 / 下一回合；出完牌、停住等交付時 = 下一位）|
| `1`–`5` | 宣告時選當前玩家的牌 |
| `U` | 復原一步 |
| `V` | 切換「操作模式 / 純顯示模式」（純顯示隱藏所有控制項）|
| `Esc` | 關閉疊層視窗（翻牌登錄關掉後，同一回合已點的牌會保留）|

## 操作員後門
- **↶ 復原**：每個動作前都存檔，可一路復原；另有「復原到回合開始」。
- **🔧 手動修正**：直接改任何狀態 — 某格噪點/毒/屍體/掉落樣本、某人的位置/樣本/陣營/殘響、牛的肥度/位置/毒劑數。現場爭議裁定用。
- **⚙ 參數**：現場改回合數、各門檻、各卡噪點、肥度門檻、移動公式等，立即生效。
- **🖥 投影視窗**：開純顯示的第二視窗給投影機。
- **＋ 新局**：清除進度，回到開場精靈。

## 設計決策 ── 已解決的規則不一致

最初的建置需求與規則書 v6 大致一致，但有一處**內部矛盾**與若干**未定義的細節**。依「若有不合理請解決」自行裁定如下，全部集中記錄，方便現場核對或事後調整。

### 1.（矛盾）結算噪點順序 vs.「屍體噪點不衰減」— 已修正
兩份文件都把結算順序列為 **① 攜帶噪點 → ② 屍體噪點 → ③ 全場衰減 → ④ 牛移動**，但同時規定「屍體噪點**不衰減**、永久存在，把牛一直拉回來」。

照字面順序，屍體噪點（步驟②）會馬上被步驟③衰減掉。在 11–14 人的 **−2 衰減**地圖上，屍體每回合 +2 又 −2 = 淨值 0，屍體格永遠不累積 → 與「全場最危險、把牛一直拉回來」直接矛盾。

**裁定**：引擎**先對既有噪點做衰減，再加入每回合的流量來源（攜帶 +1/樣本、屍體 +2）**，使這些流量當回合不被衰減。效果上屍體格穩定提供 +2（−2 圖）或持續累積（−1 圖），符合設計意圖。誘餌槽、誘導等「堆積型」噪點仍照常於下回合衰減。（見 `engine.js` 檔首說明與 `settleNoisePhase`，並有對應單元測試。）

### 2. 卡牌循環跨越 12 回合
「2→2→1」三回合會用掉全部五張牌，唯一能補牌的是**重製**（打出後該回合結束收回所有打出的牌，下回合恢復五張）。由於重製是五張之一，最遲第三回合一定會打出 → 每個三回合循環自動補牌，牌組結構自洽。引擎照此實作（`resetPending` → 回合末 `hand` 恢復）。殘響手牌為 {移動, 誘導, 互動}（互動只能操作回聲器），每回合打一張，用過任兩張就全部收回。

### 3. 肥度 4+「走幾何最短直線」在方格上的實作
四連通方格上無法走真正的斜直線。實作為**逐步取最能減少與目標歐氏距離的方向**（平手取順時針：北→東→南→西），沿途的內牆永久撞穿，外框永不撞穿。這給出貼近直線、且決定性可重現的路徑。

### 4. 目標被牆完全封死
規則：「朝目標方向強行撞穿一面相鄰的牆（無視肥度），本回合移動結束。」**實際上不會發生**：地圖永遠連通（開局保證、環境卡不能切斷、牛只拆牆），所以說明書已刪掉這條，引擎保留當作保險。實作為：牛先沿可通行最短路徑移動到**離目標歐氏距離最近的可達格**（最多走該回合格數，沿途照樣殺人），再從該格撞穿一面朝目標的相鄰牆，本回合結束、不進食。

### 5. 毒的粒度
以**房間布林值**表示「該房間噪點是否含毒」，而非追蹤每一團毒的數量 —— 對「牛吃到含毒房間 → 記一劑（一餐幾團毒只算一劑）」已足夠。房間噪點被衰減到 0 或被消音器歸零 → 毒清除；回聲器複製噪點時毒不複製。

### 6. 波及（肥度 7+）
路徑上每一格（不含起點）的**四方相鄰房間**一起殺，波及部分不撞牆、不移除牆，且穿牆也照殺（區域效果）。注意起點會是第一步的鄰格，所以肥度 7 以上站在牛起點的人也會被波及打死（說明書已寫明）。

### 7. 其他小裁定
- **地圖中央**：5×5 取 (2,2)，6×6 取 (3,3)（`floor(N/2)`）。
- **平手距離**一律用「當前牆配置下的可通行 BFS 步數」，連撞牆肥度的牛選目標時也照此定義（依規則明文）。
- **宣告隊列**含殘響，一起依離牛距離排序；距離平手取所在房間噪點高者，再平手取席位序。
- **地圖生成**：先隨機 DFS 生成生成樹（保證連通），再隨機打通約 1/3 的內牆製造環路，因此「任兩房至少一條通路」恆成立；附「重新生成」。

### 8. 牌沒有合法目標時「作廢」
實測發現約 4% 的格子上環境卡**每一面牆都動不了**（拆不到、築了會封死或切斷地圖），規則只說「重選」，但根本沒得選 → 整場卡死。宣告時每張牌都有「✖ 作廢這張牌」：牌照樣消耗、**無效果、不產生噪點**，回合繼續。中途走出出口的人，剩下的牌自動跳過。

### 9. 規則演變（v7–v19）
模擬測試後陸續修正，現行是 v19（各版改了什麼見 `平衡測試報告.md` 第三節）。程式上的重點：
- `config.js`：`FACTION_TABLE` 陣營人數（每多一人依序加給屠夫→逃亡者→飼養者）；`tableFor()` 裡的 `V13` 表依人數設定逃亡者／飼養者門檻、毒效、每箱樣本、毒死劑數；11–14 人牛步數 = 肥度 + 2。
- `firstWinEnds: 1`：任一陣營達成就結束（牛的同一次行動中達成的陣營一起贏）。
- `timeoutCowWins: 1`：第 12 回合結束沒人達成 → 牛贏。
- `teamTransfer: 1`：所有陣營都能把任意數量的樣本交給同房、同陣營的隊友（`engine.js` 的 `giveSamples`、`canTransfer`）。
- `dropAllowed: 1`：可以把樣本丟在地上，任何人用互動卡撿（`dropSamples`）。
- 毒死優先（`state.cow.dead`）；只有逃亡者能從出口離開（`tryLeaveViaExit`）；只有屠夫能下毒（`declareLure`）；消音器清自己和四鄰格（`silencerRadius`）；回聲器複製後原房間砍半（`echoHalveSource`）；毒只維持一回合（`poisonOneRound`）；樣本箱至少離牛 2 步（`boxMinDist`）；牛連續沒吃到的回合數加到步數（`cowHungerStep`，v18；下毒加成 `poisonBonus` 改回 0）；第 1 回合出口至少離樣本箱 3 步（`exitBoxMinDist`、`exitBoxFirstOnly`）；牛出發時自己那一格也會輾人（`cowStartKills`，v19）；殘響的手牌是移動／誘導／互動，互動只能操作回聲器，用過任兩張全部收回（`ECHO_CARDS`）。
- 測試用開關（預設關閉）：`breederTransfer: 1`、`breederWinAny: 0/2`、`cowLateBonus`；設成 0 可回到舊規則的開關：`firstWinEnds`、`timeoutCowWins`。
